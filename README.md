# Неоновый Залив

Браузерная 3D-гонка с открытым городом: прибрежный мегаполис на закате, пальмы и неон, трафик, полиция с уровнем розыска, уличные гонки и трамплины. Мир, названия и персонажи оригинальные.

Игра — один файл `index.html` на [three.js](https://threejs.org/) r128. Сборка не нужна.

## Как запустить

- Откройте `index.html` в браузере (Chrome, Edge, Firefox, Safari).
- Или включите GitHub Pages для ветки, и игра откроется по ссылке репозитория.

three.js грузится с cdnjs. Если CDN недоступен, подхватится локальная копия `lib/three.min.js`.

## Режимы

| Режим | Цель |
| --- | --- |
| Свободная езда | Катайтесь по городу, собирайте наличные, дрифтуйте, прыгайте с трамплинов. Протаранили машину — растёт розыск, приезжает полиция. |
| Уличная гонка | 2 круга против трёх соперников по набережной и центру, 7 чекпоинтов на круг. Призы: $5 000 / $2 500 / $1 000. |
| Побег | Старт сразу с тремя звёздами розыска. Оторвитесь от полиции и получите $3 000 плюс бонус за скорость. |

Деньги и купленные машины сохраняются в браузере (localStorage).

## Управление

| Клавиша | Действие |
| --- | --- |
| `W` / `↑` | Газ |
| `S` / `↓` | Тормоз и задний ход |
| `A` `D` / `←` `→` | Руль |
| `Пробел` | Ручник, дрифт |
| `Shift` | Нитро |
| `C` | Камера: ближе, дальше, с капота |
| `R` | Радиостанция |
| `N` | Закат или ночь |
| `H` | Сигнал |
| `M` | Звук вкл/выкл |
| `Esc` / `P` | Пауза |

На телефоне появляются сенсорные кнопки. Поддерживается геймпад: стик — руль, RT — газ, LT — тормоз, A — ручник, B/RB — нитро.

## Механики

- **Розыск (1–5 звёзд).** Аварии с трафиком и таран полиции поднимают уровень. Пока полиция вас видит, погоня усиливается. Чтобы уйти, нужно скрыться из поля зрения: звёзды мигают, а в левом верхнем углу идёт отсчёт.
- **Арест.** Если вы стоите, а рядом полицейская машина, заполняется шкала ареста. Штраф — 10% наличных.
- **Повреждения.** Шкала «Кузов» падает при сильных ударах и медленно восстанавливается. Разбитую машину эвакуируют за $500. В гонке эвакуатор возвращает вас на последний чекпоинт.
- **Бонусы.** Дрифт (множитель растёт с длительностью), проезд впритирку к трафику, стант-прыжки дольше секунды, пачки наличных на улицах.
- **Радио.** Три процедурные станции на Web Audio: «НЕОН FM», «ЗАКАТ 88», «ТУРБО РАДИО».
